This code is used for the design and optimisation of a high speed blended wing for the CAA open category

It takes geometric inputs according to 'Design of a Jet Powered Fixed Wing Uncrewed Aircraft System (UAS) Optimised for High Speed' by Findlay Smith
It then outputs the max speed of the top 20 desings and some perfomance parameters related to the best design
It also Outputs the estimated weight based on the input parameters and constants
